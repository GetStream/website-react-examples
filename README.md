The hosted apps (social-messenger, gaming-livestream, team and virtual-event, from the `-ts` folders where there are two) use [stream-chat-react v15](https://github.com/GetStream/stream-chat-react/releases/tag/v15.0.0) and [stream-chat v10](https://www.npmjs.com/package/stream-chat), which need Node 22.18 or newer. Upgrading your own app from v14? Start with the [v14 → v15 migration guide](https://github.com/GetStream/stream-chat-react/blob/v15.0.0/ai-docs/ai-migration-v14-v15.md).
